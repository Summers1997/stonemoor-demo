Records that the client was told, in writing, which compliance responsibilities are theirs.

Roughly a third of the controls are owned by the client or shared with them. The pipeline assigns
the owner; this is where the evidence lives that somebody actually told them.

Generate the document to send with:

    compliance handover --skeleton

That writes the client-facing document and an ISSUED record here, with the acknowledgement fields
left empty. Complete them when the client replies — not before.
